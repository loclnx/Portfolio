- **Heading:** 48-64px trên desktop; 36-44px trên mobile.
- **Body:** 16-18px, line-height khoảng 1.6.

## 6. Công nghệ triển khai

- **Next.js 16 + React 19 + TypeScript:** project hiện tại đã được khởi tạo theo stack này; phù hợp để xây landing page có cấu trúc component rõ ràng.
- **Tailwind CSS v4:** đã có trong dependencies; dùng để xây responsive layout nhanh và giữ design tokens nhất quán.
- **Next Font:** tải Manrope và JetBrains Mono tối ưu qua `next/font`.
- **Mock data có interface:** tách dữ liệu `projects`, `skills`, `socialLinks` thành các object TypeScript để dễ bảo trì.
- **Triển khai:** Vercel sau khi hoàn thiện và kiểm tra responsive.

Không cần backend hoặc cơ sở dữ liệu cho phiên bản đầu tiên. Form liên hệ có thể bắt đầu bằng liên kết `mailto:` để giảm độ phức tạp.
